# Solvey Admin Panel

Admin panel for Solvey medical company.

## Repository

🔗 **GitHub Repository**: [https://github.com/kamandaragasafli/solvey-admin](https://github.com/kamandaragasafli/solvey-admin)

## Description

This is the administrative panel for managing medical company operations, including:
- Doctor management
- Region and city management
- Hospital/clinic management
- Reports and analytics
- Financial tracking
- Prescription management

## Technology Stack

- **Backend**: Django (Python)
- **Frontend**: HTML, CSS, JavaScript
- **UI Framework**: Bootstrap 5
- **Icons**: Bootstrap Icons, Font Awesome

## Features

- Doctor management and tracking
- Regional and city administration
- Hospital/clinic management
- Financial reports and analytics
- Prescription tracking
- User authentication and authorization
- Excel export functionality

## Installation

1. Clone the repository:
```bash
git clone https://github.com/kamandaragasafli/solvey-admin.git
cd solvey-admin
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run migrations:
```bash
python manage.py migrate
```

4. Create a superuser:
```bash
python manage.py createsuperuser
```

5. Run the development server:
```bash
python manage.py runserver
```
